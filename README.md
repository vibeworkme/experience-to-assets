# 경험에서 교육 자산으로

강사가 교안을 만들고 강의한 내용을 녹음한 뒤, AI와 책을 만드는 과정을 보여주는 정적 웹사이트입니다. ‘의지·녹음·AI 활용’을 시작 조건으로 제시하고, 실제 강의 사례에서 일반인의 일상 기록 실습으로 연결합니다.

- 공개 사이트: https://vibeworkme.github.io/experience-to-assets/
- 목적: 제작 과정을 따라 해볼 수 있도록 자료와 판단을 공개하고, 공공기관·기업의 맞춤 워크숍 문의로 연결합니다.
- 워크숍 문의: ceo@wilab.co.kr

## 구성

- `#video-learning`: 약 1분 길이의 마이크로 러닝 영상 8개. 각 차시의 목표, 실제 예제 지면, 복사 요청문, 실습 과제, 완료 기준을 연결합니다.
- `learning.css`, `learning.js`: 차시 선택, 요청문 복사, 이 브라우저의 실습 완료 표시. 로그인·외부 추적 없이 동작하며 저장소를 사용할 수 없어도 학습할 수 있습니다.
- `media/learning/`: 자막이 포함된 H.264/AAC 영상 8개와 별도 VTT, 같은 8개 차시의 이어보기. 자동 재생하지 않고 `preload="none"`을 사용합니다.
- `downloads/learning/`: 가상 일상 기록의 실습자료 ZIP과 개별 파일, 준비 안내, 차시별 요청문, 출처. AI 답변과 앱 전체 조작을 녹화한 영상이 아니라, 요청문·예제 문서·실제 PDF 지면을 설명하는 강의입니다.

마이크로 러닝은 박희용의 기존 기준 음성을 바탕으로 로컬에서 생성한 AI 복제 음성과 기존 ACE-Step 배경음악을 사용합니다. 원본 기준 음성이나 계정 정보는 게시하지 않습니다. 음성 수정판은 대본을 전부 다시 연결하고 105개 짧은 합성 단위로 음성을 교체했습니다. 중복 도입을 제거하고 문장별 음량, 질문·강조·쉼과 자막 시점을 다시 구성했습니다. 앞 차시 결과물이 다음 차시 입력으로 이어지며, 02의 녹음에서 03의 녹취록으로 가는 전사 안내를 포함합니다. 4페이지 가상 예제와 실제 V13 워크북 50페이지를 구분합니다.

- `index.html`: 만든 목적, 세 가지 시작 조건, 실제 결과물과 이용 안내, 편집 스타일 비교, 6단계 따라하기, 일상 녹음 실습, 제작 기록, 사용 도구, 워크숍 안내
- `expansion.html`: 교육 자료에서 제품·기업 소개서로 확장하는 방법 비교
- `styles.css`, `project.css`: 반응형 스타일
- `app.js`, `project.js`: 실습 양식과 문의 양식 기능
- `assets/`: 기존 제작물의 웹용 이미지, 글꼴과 라이선스
- `media/`: 사용자가 제공한 원소스 멀티 아웃풋 소개 영상(MP4, 1분 02.7초, 약 14MB)
- `downloads/`: V13 PDF, 편집원고 ZIP, 실습자료, 표지 작업노트와 변경 기록

## 실행과 배포

별도의 빌드나 서버 프로그램은 필요하지 않습니다. 정적 HTTP 서버로 이 폴더를 제공하거나 GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다. 모든 내부 경로는 저장소 하위 주소에서도 동작하도록 상대 경로입니다.

문의는 방문자의 메일 앱에서 작성·발송하는 방식입니다. 사이트 서버에 문의 정보를 저장하거나 자동 발송하지 않습니다.

소개 영상은 `#project-film`에서 브라우저의 기본 플레이어로 재생합니다. 자동 재생 없이 `preload="none"`을 사용하며 재생 전에는 포스터만 불러옵니다. MP4는 사용자가 제공한 파일을 재인코딩 없이 복사했고, 포스터는 영상 5초 지점에서 추출했습니다.

## 사례와 출처

실증 사례는 강의 녹취록 6개를 바탕으로 만든 ‘풍류 AI실무 -01’ V13 50쪽입니다. 제품·기업 소개서는 향후 적용 예시이며 완료한 실증 사례로 표현하지 않습니다. 원천 녹취록과 계정 정보는 이 저장소에 포함하지 않았습니다.

편집 스타일 비교는 V09 세로형 해설서 6쪽, V11 가로형 워크북 9쪽, V13 일러스트 실무판 9쪽의 실제 지면을 사용합니다. 같은 강의 원천에서 발전한 판본이며 실습·예제 등 내용도 보완했습니다. 원문이 완전히 같은 레이아웃 비교로 표현하지 않습니다. 하루의 녹음으로 일기·에세이·경험집을 만드는 내용은 직접 해볼 적용 예시입니다. 제작 시간 단축률을 측정한 실험이나 자동 출판 서비스로 소개하지 않습니다.

책 제작 기반 스킬: [gongnyang/bookforge](https://github.com/gongnyang/bookforge). 이 프로젝트의 가로형 워크북은 해당 스킬을 출발점으로 조판과 검수 스크립트를 확장했습니다.

삽화는 이 프로젝트에서 AI로 만든 가상 장면이며, 실존 공연의 증거 사진이 아닙니다. Wanted Sans와 Paperlogy의 라이선스·저작권 고지는 `assets/FONT-LICENSES.txt`에 포함합니다. 편집원고 ZIP에도 원고·조판·글꼴·이미지와 관련 고지를 보존했습니다.

원본 PDF와 이전 판본은 별도로 보존했습니다.
