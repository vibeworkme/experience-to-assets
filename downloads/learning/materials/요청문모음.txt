요청문 모음 · 내 목소리에서 한 권의 책까지

01차시 · 도구보다 먼저 정할 것
이 책을 읽을 사람은 누구인가요?
읽고 나서 무엇을 할 수 있으면 좋을까요?
남기고 싶은 이야기는 무엇인가요?

02차시 · 녹음할 때 답할 세 가지
오늘 가장 기억나는 장면은?
그때 무슨 생각이 들었나요?
나중에도 남겨두고 싶은 말은?

02차시 · 내용을 묶어 달라고 요청합니다
이 녹취록에서 책에 담을 내용과 반복되는 주제를 정리해 줘.
각 항목의 원문 위치도 함께 표시해 줘.
잘못 옮겨졌을 수 있는 표현은 확인 필요로 남겨 줘.
원문에 없는 사실은 추가하지 마.

03차시 · 목차 요청문을 넣습니다
독자는 화분을 처음 돌보는 사람이야.
첨부한 내용 목록만 바탕으로 3장 목차를 제안해 줘.
장마다 핵심 질문, 사용할 원문 위치, 짧은 실습을 연결해 줘.
자료가 없는 설명은 추가 자료 필요로 표시해 줘.

03차시 · 크게 벌어진 목차를 줄이는 요청
이 목차에서 원문 근거가 없는 장은 제외해 줘.
비슷한 장은 합쳐 줘.
각 장이 답할 질문을 한 문장으로 줄여 줘.
줄인 이유와 남겨 둔 내용을 함께 알려 줘.

04차시 · 원고 요청문
첨부한 녹취록과 확정 목차로 1장 초안을 써 줘.
내 말투를 살리고 경험의 순서를 이해하기 쉽게 정리해 줘.
원문에 없는 사건, 감정, 수치, 전문 지식은 만들지 마.
불명확한 부분은 확인 필요로 표시하고 원문 위치를 별도로 적어 줘.

04차시 · 사실 대조를 표로 요청합니다
초안과 원문을 문장별로 대조해 줘.
초안 문장 / 원문 위치 / 판정 / 수정 제안을 표로 정리해 줘.
판정은 근거 있음, 근거 부족, 확인 필요로 나눠 줘.
추측한 문장을 원문 사실처럼 확정하지 마.

05차시 · 처음 만드는 책 요청문
첨부한 기준 원고로 초보자용 PDF 책을 만들어 줘.
먼저 BookForge와 필요한 실행 도구의 설치 상태를 확인해 줘.
표지, 목차, 본문, 짧은 실습, 출처를 넣어 줘.
원문에 없는 사실은 추가하지 말고 편집 가능한 원고와 제작 파일도 남겨 줘.

05차시 · 공개 워크북을 그대로 재제작하기
공개 사이트 → 편집 자료 받기 → 압축 풀기

Codex 요청:
이 폴더의 README-V13.md를 읽고
build-workbook.mjs를 실행해 PDF를 만들어 줘.
verify_workbook.py로 검수하고 결과를 알려 줘.

내부 실행: node build-workbook.mjs

06차시 · 수정 요청은 위치와 증상을 함께
PDF 3쪽의 실습 질문과 작성 칸이 너무 멀리 떨어져 있어.
질문 바로 아래에 작성 칸을 배치해 줘.
본문 내용은 바꾸지 말고 수정 파일을 새 버전으로 저장해 줘.
바뀐 페이지를 이미지로 보여 주고 이전 버전과 비교해 줘.

06차시 · 한 원고로 다른 결과 만들기
이 기준 원고를 짧은 워크북으로 바꿔 줘.
설명은 줄이고 장마다 질문 1개와 작성 공간을 넣어 줘.
새로운 사실은 추가하지 마.
독자와 목적이 달라지면 바꿔야 할 부분도 알려 줘.
