공개 사례를 동일하게 재제작하려면
https://vibeworkme.github.io/experience-to-assets/ 에서 '편집 자료 받기'를 다운로드하고 압축을 풉니다.
Codex에서 다운로드한 편집 폴더를 열고 'README-V13.md를 읽고 PDF를 다시 제작하고 검수해 줘'라고 요청하세요.
해당 프로젝트는 Node.js 22, Typst 0.14.2, Python, PyMuPDF가 필요합니다. 제작 명령은 node build-workbook.mjs, 검수는 python3 verify_workbook.py입니다.
출력은 draft/book.pdf이며 전용 검수 통과 후 final/book.pdf입니다. 공개 V13은 BookForge를 확장한 전용 워크북이므로 기본 스킬만 실행해서 같은 모양이 되지는 않습니다.

사용하는 AI의 답변과 화면은 서비스·버전에 따라 다릅니다. 예제 결과는 정답 형식을 익히는 자료이며 실제 실행 답변이 동일하다는 보장이 아닙니다.
최종 판단은 원본 녹음과 내용 대조, PDF 전 페이지 열람으로 합니다.
